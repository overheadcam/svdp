Site images.

Place three logo files here:

    svdp_ctx_logo.png   -> round crest at the top-left (links to ssvdp.org)
    st-austin-logo.png  -> right of "Vincentian Resource Center" (links to staustin.org)
    servware-logo.png   -> the "Open ServWare" button on the Home Visits page

The site loads them from img/. If svdp_ctx_logo.png is missing, the crest
falls back to a gold "SVdP" circle; if st-austin-logo.png is missing, that logo
area is hidden; if servware-logo.png is missing, the ServWare button shows the
text "Open ServWare" instead. Either way the site still works without them.

A PNG with a transparent or white background works best; it is shown about 52px
tall inside a white rounded box. Other formats work too if you keep the
filename's extension in sync with the header (index.html) — PNG is simplest.
